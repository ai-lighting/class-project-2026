1. Project Overview

Design a complete, compliant lighting scheme for a hypothetical car dealership covering:

  • Interior lighting (AS/NZS 1680.1)
  • Exterior pedestrian and car-park lighting (AS/NZS 1158.3.1)
  • Emergency lighting and exit signs (AS/NZS 2293.1)
  • Daylighting integration for the workshop

Use Relux to model, analyse and document the design.

Working Style

We work through each topic together as a group during sessions. Each student takes ownership of the section(s) most relevant to their role or interest. Individual contributions come together as one cohesive scheme by the end of the project.

Evaluation & Submission

The primary deliverable is a Relux export file (.recad).

A .recad file is Relux's project export container. It bundles your project model, luminaire data, calculation surfaces and results into a single shareable file. It's produced from Relux via File → Export → Relux Project (.recad) and can be re-opened in any compatible Relux installation, so the marker can step through exactly what you built.

Provisions for submitting work and recording results online will be provided as the project progresses. Until that's live, share files through the project channel.

AS/NZS 1158 Compliance

Verified using the Compliance Calculator tool, not by hand. It takes the photometric data and design layout and reports pass / fail against the standard.

AS/NZS 4282 — Obtrusive Outdoor Light

Mentioned for completeness so you know it exists and applies in real practice. Not required as a deliverable for this project due to time.

Showroom (R5) — Creative Brief

The showroom is part of the premade Relux scenes supplied with the project file. It is deliberately set up as an abstract space with plenty of opportunity for creative lighting design.

AS/NZS compliance is not the goal here. The brief is to express creative intent and apply it through Relux. Treat it as a design and visualisation exercise rather than a compliance task. Use it to explore accent vs ambient, vertical illuminance on vehicles, mood, colour temperature, layering, and any other creative tools Relux gives you.

3. Technical Requirements

3.1 Interior lighting (AS/NZS 1680.1)

  • Meet the Em target shown in the room table, and the Uo (min / avg) value recommended by AS/NZS 1680.1 for the task type. State Em and Uo achieved.
  • Choose fixtures based on photometric distribution (IES / ULD), not just nominal beam angle.
  • State your modelling assumptions in the form set out in Section 7.

3.2 Exterior lighting (AS/NZS 1158.3.1)

  • Meet Category P targets for the assigned sub-category.
  • Compliance is checked through the Compliance Calculator tool using photometric data and the design layout from Relux.
  • For E3, mount asymmetric optics at 10 m on the building with zero tilt unless you can justify otherwise.

3.3 Daylighting — Warehouse / Workshop (R1)

  • Use skylights to achieve maintained Em ≥ 600 lx and Uo ≥ 0.6 at the working plane under CIE overcast.
  • Set the Relux project location to Australia.
  • Simulate and document CIE overcast, CIE clear, and CIE clear with sun.
  • Briefly explain (a few sentences each): glare from sky exposure; shading or diffusion strategy; how electric lighting is dimmed or switched in response to daylight.

3.4 Emergency lighting & exit signs (AS/NZS 2293.1 + 2293.3)

  • Show that the centreline path-of-travel illuminance required by AS/NZS 2293.1 is achieved at floor level along each escape route. Include a Relux plot along the path.
  • Select exit signs so that the sign's rated viewing distance under AS/NZS 2293.3 is greater than or equal to the longest line-of-sight from any decision point in the space.
  • State the system duration per AS/NZS 2293.1 (90 min standard).
  • For each emergency luminaire, state its AS/NZS 2293.3 classification (e.g. C0, D80) and the spacing / quantity that follows from its spacing table.

NCC Section J — Part J7 (Lighting)

Section J7 energy compliance is read directly from your .recad file by the Compliance Calculator: installed load (W and W/m²), control strategy and allowance check are derived automatically from the Relux model. You don't need to populate a separate energy spreadsheet by hand. Make sure your luminaires in Relux carry correct wattage data so the calculator can read it.

Submission Channel

5.1 Relux export file (primary deliverable)

  • Export your Relux project as a .recad container via File → Export → Relux Project (.recad). This bundles the model, luminaires, calculation surfaces and results into one shareable file.
  • The file shows your full design contribution and can be opened by the marker exactly as you built it.

  • Don't change supplied room IDs.

5.2 Short assessment summary (one per space / area worked on)

Keep it to roughly one page per space, structured under the same headings every time:

  • Target — Em / Uo / category target from the brief.
  • Achieved — Em / Uo from the Relux calculation.
  • Photometric justification — luminaire family, distribution type, optical control, CCT / CRI used.
  • Controls — switching, occupancy / daylight sensors where relevant.
  • Design considerations — aesthetics, function, sustainability.
  • Non-compliances and mitigation — anything that doesn't hit target, and why / what you'd do.

Format can be spreadsheet rows or a one-pager per area. Will move into the online submission system once it's ready.

5.3 Daylighting summary (R1 only)

  • Skylight type, size and placement.
  • Simulation results under CIE overcast, clear and clear with sun.
  • Em and Uo achieved under each sky.
  • Rationale for the daylight / electric-lighting interaction.

5.4 Emergency & exit summary

  • Escape-route layout with the Relux centreline-illuminance plot.
  • Exit-sign selection table: viewing-distance class, pictogram, placement, decision points covered.
  • Per-luminaire AS/NZS 2293.3 classification, spacing table reference, achieved spacing and quantity.
  • System duration statement.

5.5 Relux design report (export)

A concise PDF export from Relux showing calculation settings, targets vs achieved, key views, and the emergency / exit summary.

6. Assessment Criteria

  • Compliance with the AS/NZS standards relevant to your sections. Flag any non-compliances honestly with proposed mitigations.
  • Technical accuracy of Relux results, traceable to the .recad file submitted.
  • Design effectiveness. Fixture choice and placement justified by the luminaire's photometric distribution, beam angle and mounting context, with the justification recorded in the assessment summary.
  • Energy performance. NCC Section J7 check passes when the Compliance Calculator reads your .recad file (luminaire wattage data must be present in the Relux model).
  • Innovation & creativity. Quality of the showroom concept and any optional Level 1 work; design intent stated.
  • Documentation. The .recad file opens cleanly, calculation surfaces are named per the room IDs, and every space worked on has a one-page summary covering target, achieved and design intent.
  • Contribution. Measured by what's visible in the section(s) you took on.

7. Modelling Notes (state in your submission)

  • Workplane heights: 0.7 m for desks, 0.0 m for circulation. Adjust per space if needed.
  • Grid spacing: tight enough to give usable resolution. Typical guidance: 0.25–0.5 m for small rooms, 0.5–1.0 m for larger spaces, ≥ 1.0 m for car parks. State the value you used.
  • Maintenance factor (MF): state the MF used and the method (single-value or product-based).
  • Per-luminaire data to report: CCT, CRI and rated wattage. The wattage is read by the Compliance Calculator for Section J7.
  • Surface reflectances: state the values used for ceiling / walls / floor.
  • Photometric sources: ReluxNet preferred so fittings can be swapped during suitability checks.
  • Exterior tilt: 0° preferred for boundary control unless justified.
